# 데이터 출처 및 운영 원칙

POPOK Knowledge는 국내 무용 및 공연예술 매체가 공개적으로 게시한 리뷰, 프리뷰, 기사를 수집하여 예술가·단체·작품·공연·공연장 정보로 구조화하는 아카이브입니다. 이 페이지는 데이터가 어디서, 어떤 기준으로 수집·정리되는지를 안내합니다.

## 주요 데이터 출처

현재 3개 매체를 수집 대상으로 합니다. 아래 명칭·주소는 실제 수집기 코드(`app/parsers/`, `scripts/run_collect*.py`)와 각 사이트를 직접 확인한 값입니다.

| 매체 | 공식 주소 | 내부 source 값 | 수집 건수 |
|---|---|---|---|
| DanceWebzine | koreadance.kr (공식 명칭 확인 필요 — 사이트 SSL 인증서 만료로 자동 확인 불가) | `dancewebzine` | 780건 |
| 한국춤문화자료원 · 댄스포스트코리아 (DancePostKorea) | dancepostkorea.com | `dancepostkorea` | 665건 |
| The Preview | thepreview.co.kr (공식 명칭 확인 필요 — 사이트 SSL 인증서 만료로 자동 확인 불가) | `thepreview` | 1,384건 |

- "댄스포스트코리아" 명칭은 해당 사이트의 페이지 메타 정보와 수집기 코드(`app/parsers/dancepost_parser.py`) 양쪽에서 확인되었습니다.
- DanceWebzine과 The Preview는 수집기가 실제로 접속해 사용하는 주소(URL)는 코드로 확인되지만, 사이트의 SSL 인증서가 만료되어 있어 공식 명칭·로고를 자동으로 재확인하지 못했습니다. 추측으로 명칭을 만들지 않고 내부에서 쓰는 식별값(`source` 컬럼 값)을 그대로 표기했습니다.
- 게시일 표기 형식이 매체마다 달라(일부는 자유 텍스트) 정확한 수집 기간(예: "2019년~2026년")을 이 페이지에 확정 수치로 제시하지 않습니다. 정확한 게시일은 각 기사 원문에서 확인해주세요.

## 아카이빙 기준

- 각 기사는 리뷰/프리뷰/뉴스/인터뷰/에세이/칼럼 등으로 분류됩니다. 분류가 아직 확인되지 않은 기사는 "분류 미완료"로 표시되며, 임의로 리뷰 등으로 단정하지 않습니다.
- 기사 본문에서 AI가 예술가·단체·작품·공연 정보를 추출하되, 추출된 문구가 원문에 실제로 존재하는 그대로인지(verbatim) 검증한 뒤 근거(evidence)로 함께 보관합니다.
- 서로 다른 기사에서 이름이 비슷한 예술가·단체·작품이 발견되면 자동으로 병합하지 않고, 사람이 검토하는 대기열(Review Queue)에 후보로만 올립니다.
- 이러한 처리 특성상 일부 항목은 아직 검증되지 않은(추론된) 상태로 표시될 수 있습니다.

## 저작권 안내

- 원문 기사의 저작권은 해당 매체 및 필자에게 있습니다. POPOK Knowledge는 원문 전체를 재게시하지 않으며, 서지정보(제목·매체·게시일·필자)와 근거 인용을 위한 짧은 발췌만 보관합니다.
- 각 기사 페이지에는 원문 링크가 함께 제공됩니다.
- 저작권자가 게시 중단을 요청하는 경우 해당 항목을 삭제하거나 비공개로 전환합니다.

## 정보 오류 및 정정 요청

- 예술가·단체·작품 정보가 잘못 연결되었거나 사실과 다른 부분을 발견하시면 알려주시기 바랍니다.
- 현재 별도의 정정 요청 접수 채널이 마련되어 있지 않습니다 (준비 중입니다). 시급한 정정이 필요한 경우 원본 매체에 직접 문의해주세요.

## 원문 확인 안내

POPOK Knowledge의 요약·분류·연결 정보는 원문을 대체하지 않습니다. AI 기반 자동 추출 과정에서 오류가 발생할 수 있으므로, 정확한 내용은 반드시 각 기사의 원문을 통해 확인해주시기 바랍니다.
